Connect the Bitunix Telegram group

  1. Create a bot with @BotFather. Copy the token into TELEGRAM_BOT_TOKEN.
  2. Turn privacy off: /setprivacy → Disable. Add the bot to the Bitunix futures group.
  3. Run python tools/telegram_listen.py --discover, copy the group chat_id into TELEGRAM_CHAT_ID.
  4. Leave python tools/telegram_listen.py running. New signals land in this inbox.
